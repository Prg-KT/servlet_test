フィルタチェーン

A前 → B前 → Servlet → B後 → A後

chain.doFilter()より前が前処理、後ろが後処理です。

JDBCの基本手順

接続 → SQL準備 → 値設定 → SQL実行 → ResultSet処理 → クローズ

頻出： removeAttribute()は属性1個を削除し、 invalidate()はセッション全体を無効化します。
